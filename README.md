# Онлайн-запись на ремонт стекла

Портфолио-демо с тремя экранами. На экране записи можно выбрать услугу, день и время. На экране мастера можно отменить и восстановить запись. В учёте можно посмотреть все записи или отфильтровать их по статусу.

Расписание и автомобили вымышлены. Изменения хранятся в памяти текущей вкладки до перезагрузки. Формы для контактов и свободного текста отсутствуют. Приложение работает из статических файлов, не требует базы данных и не отправляет данные.

## GitHub Pages

Загрузите файлы из этой папки в корень отдельного публичного репозитория. В Settings → Pages выберите Deploy from a branch, ветку main и папку /(root), затем сохраните настройки.
